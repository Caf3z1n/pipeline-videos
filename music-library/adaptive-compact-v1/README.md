# Biblioteca do perfil compacto devocional

Esta biblioteca é exclusiva de projetos `adaptive_compact_v1` e deve conter exatamente:

- `Aloboi .mp3`
- `Leaning.mp3`

Os arquivos de áudio são locais e permanecem ignorados pelo Git. O pipeline bloqueia outras faixas
nesse perfil e falha de forma explícita se uma das duas estiver ausente.
